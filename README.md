# Sistema Especialista para Diagnóstico de Problemas em Computadores

## Descrição

Projeto acadêmico desenvolvido para a disciplina de Ciência da Computação.

O projeto consiste em um Sistema Especialista desenvolvido em Python para auxiliar na identificação de possíveis problemas relacionados ao funcionamento de computadores.

O sistema realiza perguntas ao usuário sobre sintomas apresentados pelo computador e utiliza uma base de conhecimento e regras de produção para identificar possíveis causas e apresentar recomendações.

## Objetivo

Desenvolver um Sistema Especialista capaz de analisar sintomas apresentados por um computador e, com base em uma base de conhecimento e regras previamente estabelecidas, apresentar possíveis diagnósticos e recomendações.

## Tecnologias utilizadas

* Python
* GitHub
* Figma

## Base de conhecimento

A base de conhecimento contém informações sobre sintomas, possíveis problemas e recomendações relacionadas ao funcionamento de computadores.

A base completa está disponível no arquivo `base_conhecimento.txt`.

## Regras

O sistema utiliza regras de produção para relacionar os sintomas informados pelo usuário aos possíveis diagnósticos.

As regras completas utilizadas no sistema estão disponíveis no arquivo `regras.txt`.

## Execução

Para executar o sistema, é necessário possuir o Python instalado.

No terminal, execute:

```bash
python sistema_especialista.py
```

Em seguida, responda às perguntas apresentadas pelo sistema.

## Finalidade

Este projeto possui finalidade acadêmica. Os diagnósticos apresentados pelo sistema são possibilidades baseadas nas regras e na base de conhecimento desenvolvidas para o projeto e não substituem uma avaliação técnica profissional.
